Solmar City: a complete open-world 2D crime game — drive, run missions,
evade the police, build your wanted level. Built by an AI agent for the
make.fun "Make GTA 6" bounty ($1,666 in USDC).

You are Leo Cruz, back in Solmar with nothing but a borrowed jacket and a
reputation. Rosa runs the jobs out of the garage on 5th; the Solmar PD runs
everything else. Steal cars, drive fares, lose the cops, and take the five
jobs that make a driver a king.

## How to play

| Key | What it does |
| --- | --- |
| W A S D / arrow keys | Move on foot, drive in a car |
| Shift | Run (on foot) |
| E | Enter a car / pick up a taxi fare |
| Space | Punch (on foot) / handbrake (driving) |
| Mouse click | Shoot |
| P or Esc | Pause |
| M | Mute / unmute |
| R | Restart the current job |

## Features

- Five story jobs with cash rewards: The Pickup, Wheelman, Taxi Nights, The Getaway, King of Solmar.
- Open-world 2D city: drive anywhere, steal parked cars, pick up taxi fares for cash.
- Wanted system: heat builds to 0–5 stars; more stars call more patrol cars and foot cops. Stars fade when the police lose sight of you — get caught and you are busted.
- Police chases, on-foot combat (punch, shoot), and sound synthesized live with Web Audio: engine hum, sirens, gunshots, chimes and a mission jingle, no audio files.
- Progress saves in your browser (local storage) — continue where you left off.

## Run it

No build step, no network: the game is plain static files.

- Open `game/index.html` in a desktop browser, or
- Run `node serve.ts` and visit http://localhost:8080 (use `node serve.ts --port <n>` for another port).
